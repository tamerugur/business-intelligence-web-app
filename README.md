# personel-portal
- install **node.js**
- install **MongoDB** && **MongoDB Compass**
- create database called **personel_portaldb**

## Getting started

1. Open Terminal
2. ``` cd app && npm install ```
3. ``` cd ../web && npm install ```
4. ``` cd .. npm install ```
5. ``` npm start ```

- [http://localhost:3000](url) => API 
- [http://localhost:3001](url) => WEB
